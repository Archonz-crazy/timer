## About

**timer** is a simple, persistent timer built for macOS. It allows users to track time reliably, even across restarts, making it useful for productivity, time management, and task tracking.

## Features

- Persistent timer that continues across application restarts
- Simple and clean interface (macOS)
- Built with TypeScript and HTML
